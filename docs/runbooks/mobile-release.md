# Mobile release builds (P4-W22-S05, ADR-0013, Q-P4-04)

Release builds are made locally; nothing is submitted. TestFlight, Play internal testing and the stores are the owner's, after Phase 7.

## Art and listing

- Icons and the splash: `apps/mobile/assets/` (the PWA's placeholder mark). Regenerate with `python3 apps/mobile/scripts/make_icons.py`, or replace the PNGs with real art: `icon.png` is 1024² RGB (no alpha), `adaptive-foreground.png` and `splash-icon.png` are 1024² RGBA, drawn on #1f2933 by the platform.
- Store text: `apps/mobile/store/ios.md` and `android.md`. These are provisional drafts.
- Version: `expo.version` in `apps/mobile/app.json`, plus `ios.buildNumber` and `android.versionCode`, each raised for every store build.

## iOS (Release, simulator: no signing)

```sh
cd apps/mobile
npx expo prebuild --platform ios --clean
xcodebuild -workspace ios/Interval.xcworkspace -scheme Interval \
  -configuration Release -sdk iphonesimulator -derivedDataPath /tmp/interval-ios build
# The app: /tmp/interval-ios/Build/Products/Release-iphonesimulator/Interval.app
```

A device build, or an archive for TestFlight, needs the owner's Apple team (set `DEVELOPMENT_TEAM` on the command line, since `ios/` is regenerated): `xcodebuild … -sdk iphoneos -archivePath /tmp/Interval.xcarchive archive DEVELOPMENT_TEAM=<team>`, then `xcodebuild -exportArchive -archivePath /tmp/Interval.xcarchive -exportOptionsPlist <options.plist> -exportPath /tmp/interval-ipa` with an App Store Connect export options plist.

## Android (release APK)

```sh
cd apps/mobile
npx expo prebuild --platform android --clean
cd android && ./gradlew assembleRelease
# The APK: android/app/build/outputs/apk/release/app-release.apk
```

Expo's template signs a release with the debug key. For Play, the owner makes an upload key (`keytool`) and keeps its path and passwords in `~/.gradle/gradle.properties` (never in the repo). Since `android/` is regenerated by every prebuild, nothing generated is edited; the key goes in on the command line:
`./gradlew bundleRelease -Pandroid.injected.signing.store.file=$KEYSTORE -Pandroid.injected.signing.store.password=$STORE_PW -Pandroid.injected.signing.key.alias=$ALIAS -Pandroid.injected.signing.key.password=$KEY_PW`.

The native folders (`ios/`, `android/`) are generated, ignored by git, and left out of Docker builds.
